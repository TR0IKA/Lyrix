# Lyrix
Текст песни поверх экрана (Android 8+).

## Сборка APK через GitHub
1. Залей проект в репозиторий (ветка main).
2. Вкладка **Actions** → **Build APK** → дождись зелёной галочки.
3. Внизу страницы запуска: **Artifacts → Lyrix-debug-apk** → скачай и установи.

## Первый запуск
1. Выдай «Показ поверх других приложений» и «Доступ к уведомлениям».
   Если переключатель серый: Настройки → Приложения → Lyrix → ⋮ → «Разрешить ограниченные настройки».
2. Нажми START, включи музыку.

Тексты берутся с lrclib.net (синхронизированные .lrc).
